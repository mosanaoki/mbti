# 🌸 MBTI診断アプリ (Next.js + GSAP) 🚀

ようこそ！5問で気軽にタイプ診断できる Next.js + GSAP デモです 💡  
アニメーションたっぷりで、ふわっと MBTI を体験できます ✨

## 🎁 できること

- 🎯 5問の質問でサクッとタイプ推定
- 💃 GSAP でカードやプログレスバーがスムーズに動く
- 🗂️ Next.js App Router でページ構成もシンプル
- 📱 モバイルファーストなスタイルでスマホ表示も快適

## ⚙️ セットアップ

1. 🔧 Node.js 18 以上をインストール
2. 📦 依存関係を取得
   ```bash
   npm install
   ```
3. ▶️ 開発サーバーを起動
   ```bash
   npm run dev
   ```
4. 🌐 ブラウザで `http://localhost:3000` を開いて診断スタート！

## 🗺️ プロジェクト構成

- `app/page.tsx` トップ画面（診断開始ボタン ✨）
- `app/quiz/page.tsx` 診断ページ（カードがフェード＆スライド 💨）
- `app/result/page.tsx` 結果ページ（`?type=XXXX` を表示 🧠）
- `lib/mbti.ts` 設問とスコアリングロジック 🧮
- `app/globals.css` ベーススタイル（一部 GSAP 用の調整も 👟）

## 🧭 診断フロー

1. 🌟 「診断をはじめる」をクリック
2. 📝 5問に回答（アニメでテンションアップ 🎉）
3. 🚀 自動で結果ページへ遷移してタイプを表示

## 💡 開発メモ

- 📊 5問なので簡易版です。設問や重み付けを増やせば精度アップ 🔍
- 🎨 GSAP はクライアントコンポーネントでのみ使用しています
- 🔁 タイブレイクは E/S/T/J を優先してタイプを確定させています

楽しくハックして、自分や友だちのタイプをチェックしてみてくださいね 😄🌈
